Factory Inventory Management System

A full-stack demo: a Vue 3 single-page app talks over REST to a FastAPI service that serves and filters in-memory data loaded from JSON files. There is no database.

Data flow

  1. User sets filtersTime period, warehouse, category, order status are held as shared singleton refs in useFilters.
  2. View requests dataA view calls api.getOrders(getCurrentFilters()); api.js skips any filter set to all and builds the query string.
  3. FastAPI filters in memoryThe route runs apply_filters (warehouse, category, status) and filter_by_month (month or quarter, e.g. Q1-2025) over the preloaded lists.
  4. Pydantic validates the responseResults are serialized through the response models and returned as JSON.
  5. UI derives and rendersRaw data lands in refs; totals, charts and tables are computed properties that re-render reactively.
